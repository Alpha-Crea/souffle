Souffle

Parlez, le texte s'écrit là où vous tapez.

Souffle est une application de dictée vocale. Vous appuyez sur un raccourci clavier, vous parlez normalement, vous ré-appuyez — et votre texte apparaît dans l'application où vous étiez : Outlook, Word, Teams, un navigateur, n'importe quel champ de saisie.

Ce n'est pas de la simple transcription. Les « euh », les hésitations et les phrases reprises en cours de route sont retirés, la ponctuation et l'orthographe sont corrigées. Vous parlez comme vous parlez ; ce qui s'écrit est propre.

Installation

1

Décompressez le dossier

Clic droit sur Souffle-Windows.zip → Extraire tout… → Extraire. Placez le dossier obtenu où vous voulez, par exemple dans vos Documents.

2

Double-cliquez sur Souffle.exe

Windows affichera un avertissement bleu « Windows a protégé votre ordinateur ». C'est normal : l'application n'est pas signée par un certificat commercial. Cliquez sur Informations complémentaires, puis sur Exécuter quand même.

3

Collez une clé pour l'intelligence artificielle

La fenêtre de réglages s'ouvre toute seule au premier lancement. Il faut une clé pour que Souffle puisse transcrire — voir la section suivante.

Souffle n'a pas de fenêtre principale. Une fois lancé, il vit dans la zone de notification, en bas à droite près de l'horloge. Si vous ne voyez pas son icône, cliquez sur la petite flèche qui déplie les icônes cachées, et faites-la glisser dans la barre pour l'avoir sous la main.

La clé d'API, en trois minutes

Souffle envoie votre voix à un service qui la transcrit. Le plus rapide et le moins cher s'appelle Groq, et il propose un usage gratuit largement suffisant.

  1. Allez sur console.groq.com/keys et créez un compte.
  2. Cliquez sur Create API Key, donnez-lui un nom, copiez la clé (elle commence par gsk_).
  3. Dans Souffle : onglet Intelligence → champ Groq → collez la clé.
  4. Cliquez sur Tester à côté. Vous devez lire « Groq répond ».

Puis réglez les deux modèles, juste au-dessus :

ChampValeur à saisir
Transcription → FournisseurGroq
Transcription → Modèlewhisper-large-v3
Mise en forme → FournisseurGroq
Mise en forme → Modèlellama-3.3-70b-versatile

C'est tout. Fermez la fenêtre, Souffle est prêt.

Utilisation quotidienne

Cliquez dans le champ où vous voulez écrire, puis :

GesteEffet
Ctrl + Maj + EspaceDémarre la dictée
Le même raccourci à nouveauTermine et écrit le texte
ÉchapTermine et écrit le texte
Clic sur la pastillePause, puis reprise (ce qui est déjà dit part dans l'historique)
Glisser la pastilleLa déplace, elle reste où vous la posez
Clic droit sur la pastilleAnnule, rien n'est écrit

Pendant que vous parlez, une pastille noire apparaît en bas de l'écran avec un petit histogramme qui bouge au son de votre voix. Si l'histogramme ne bouge pas, le micro n'entend rien : vérifiez lequel est sélectionné dans les paramètres de Windows.

Comptez une à deux secondes entre la fin de votre phrase et l'apparition du texte.

Deux réglages qui changent tout

La langue

Onglet Intelligence → section Langue écrite. Deux choix, et ils sont très différents :

  • La langue que je parle — vous parlez anglais, le texte sort en anglais. C'est de la transcription fidèle, corrigée et ponctuée. Aucune traduction.
  • Traduire vers… — vous parlez dans n'importe quelle langue, le texte sort dans celle que vous avez choisie.

Le moteur de transcription ne reconnaît qu'une seule langue par dictée. Si vous mélangez français et allemand dans la même phrase, le résultat sera mauvais. Terminez la dictée, relancez-la, et parlez l'autre langue. Pour un meilleur résultat encore, indiquez la langue à l'avance : icône Souffle dans la zone de notification → Langue parlée.

Le mode direct

Onglet Général → Mode direct. Le texte s'écrit phrase par phrase pendant que vous parlez, au lieu d'arriver d'un bloc à la fin. Souffle repère vos silences et envoie chaque phrase dès qu'elle est terminée. Agréable pour les textes longs.

Pour aller plus loin

Le vocabulaire. Onglet Vocabulaire : ajoutez-y les noms propres, les marques et le jargon de votre métier, un par ligne. Sans ça, un nom d'entreprise inhabituel sera écrit phonétiquement. C'est le réglage qui améliore le plus les résultats au quotidien.

Les raccourcis de texte. Toujours dans Vocabulaire : dites « mon adresse mail », Souffle écrit l'adresse complète.

Le ton. Onglet Intelligence : neutre, formel, détendu, ou brut (ponctuation seulement, aucune réécriture). Vous pouvez aussi fixer un ton différent par application — formel dans Outlook, détendu dans Teams.

L'historique. Toutes vos dictées sont conservées sur votre machine, avec un bouton Copier. Si un texte part dans la mauvaise fenêtre, il n'est jamais perdu.

Si quelque chose ne va pas

SymptômeQue faire
Le raccourci ne fait rien Un autre logiciel l'utilise déjà. Réglages → Général → cliquez le champ Raccourci global et tapez une autre combinaison, par exemple Ctrl+Alt+D.
« Micro refusé » Paramètres Windows → Confidentialité et sécurité → Microphone → autorisez les applications de bureau.
L'histogramme ne bouge pas Le mauvais micro est sélectionné dans Windows, ou il est coupé.
Le texte va dans la mauvaise fenêtre Ne changez pas de fenêtre pendant la dictée. Souffle essaie de revenir à la bonne, mais le plus sûr est de rester là où vous écrivez.
Rien ne s'écrit, mais le texte existe Il est dans le presse-papier : faites Ctrl+V. L'historique le contient aussi.
« Clé API refusée » La clé a été mal collée ou révoquée. Recréez-en une sur console.groq.com.

Confidentialité

L'audio de chaque dictée est envoyé au fournisseur que vous avez choisi, le temps de la transcription, puis effacé de la mémoire. Rien n'est envoyé ailleurs, et il n'y a aucune télémétrie.

Votre clé d'API est chiffrée par Windows lui-même et n'est jamais écrite en clair. L'historique reste sur votre disque ; le mode confidentialité, dans l'onglet du même nom, désactive complètement son enregistrement.

Si votre organisation interdit l'envoi de données vers un service externe, Souffle accepte un point d'accès local (LM Studio, Ollama, whisper.cpp) dans le champ Endpoint personnalisé : plus rien ne quitte alors la machine.
