Souffle
—

Général

Comment déclencher la dictée et où le texte atterrit.

Cliquez puis tapez la combinaison souhaitée.
Le texte s'écrit phrase par phrase pendant que vous parlez, au lieu d'attendre la fin.
Sinon, le texte reste dans le presse-papier.
Déconseillé. Tant que le texte y reste, un ⌘V rattrape n'importe quel collage manqué ; le restaurer trop tôt fait perdre la dictée.
Le texte va là où vous avez commencé à parler, même si vous avez changé de fenêtre.
Un bip au début, un à l'insertion.
Souffle vit dans la barre de menus.

Autorisations système

Indispensable pour capter la voix.
Permet à Souffle d'envoyer ⌘V à l'application active.

Intelligence

Un modèle transcrit, un second réécrit proprement.

Transcription

Tous compatibles API OpenAI.
Pour l'allemand ou l'anglais, préférez whisper-large-v3 : la version « turbo » est distillée et perd en précision hors du français et de l'anglais.
Ex. http://localhost:1234/v1
Whisper ne détecte qu'une seule langue par dictée : forcer la bonne améliore nettement le résultat. Le menu de la barre de menus permet d'en changer en un clic.

Langue écrite

Quelle que soit la langue parlée, le texte sortira dans celle-ci.

Mise en forme

Retire les « euh », ponctue, garde la dernière reformulation.
gpt-4o-mini, llama-3.3-70b-versatile…
Surchargé par app dans l'onglet Vocabulaire.

Clés API

platform.openai.com
console.groq.com
Laissez vide si non requise.

Vocabulaire

Ce que Souffle doit écrire correctement du premier coup.

Un terme par ligne : noms propres, marques, jargon métier.

Raccourcis de texte

Dites le déclencheur à l'oral, Souffle insère la valeur.

Ton par application

Le nom doit correspondre à l'app active (ex. Slack, Mail, Notion, Terminal).

Historique

Stocké uniquement sur cette machine.

Confidentialité

Ce qui sort de la machine, et ce qui y reste.

Aucune dictée n'est conservée sur le disque.
Nombre de dictées gardées.

Statistiques

L'audio est envoyé au fournisseur choisi, puis supprimé de la mémoire. Les clés API sont chiffrées par le trousseau du système. Pour un traitement 100 % local, pointez les deux fournisseurs sur un endpoint personnalisé (whisper.cpp, LM Studio, Ollama).
